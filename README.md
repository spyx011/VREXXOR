# 🎮 VREXXOR

**A 2D platformer built with Godot Engine and GDScript.**

VREXXOR is a Mario-inspired platformer where players jump through levels, avoid hazards, defeat enemies, and reach the finish!

## ✨ Features

- 🎮 Main menu with Start Game, Options, and Exit
- 🗺️ Four playable levels
- 🏃 Player movement and jumping
- 👾 Enemies and hazards
- 💀 Death and restart mechanics
- 🏆 Winner screen and level progression
- 🔊 Sound effects and animations

## 🛠️ Built With

- **Engine:** Godot Engine
- **Language:** GDScript
- **Version Control:** Git and GitHub

## 🚀 How to Play

1. Download or clone this repository.
2. Open Godot Engine.
3. Import the project by selecting `project.godot`.
4. Press **F5** to run the game.
5. Select **Start Game** and enjoy!

## 🎯 Goal

Reach the finish point in each level, avoid hazards, and complete all four levels!
